# Keylogger 🕵️‍♂️

A Python‑based keylogger script designed to capture and record keyboard input.  
This project is for **educational and ethical cybersecurity learning only** — do **not** use it on systems without explicit permission.

---

## ⚠️ Disclaimer

Keyloggers can be **misused for malicious purposes**.  
**Unauthorized use is illegal and unethical.**  
Only run this on your own machine or systems where you have permission.

---

## 🚀 Features

- Captures keyboard keystrokes in real time.
- Logs all input to a text file.
- Lightweight and simple Python implementation.

---

## ▶️ Usage

1. Clone the repository
   ```bash
   git clone https://github.com/tharindu-L/Keylogger.git
   cd Keylogger
   '''
2. Run the keyloger
   ```bash
   python keylogger.py
   '''
